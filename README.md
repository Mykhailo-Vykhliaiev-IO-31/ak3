# Лабораторна робота №2

## Дисципліна

Архітектура комп’ютерів

## Тема

Основні інструкції 32-бітного ARM процесора для мікроконтролерів

## Виконав

Вихляєв Михайло, група ІО-31

## Мета роботи

Навчитися використовувати основні асемблерні інструкції ядра Cortex-M4, працювати з процедурами в GAS Assembly, виконувати обчислення за індивідуальним варіантом та перевіряти результат виконання програми за допомогою емулятора QEMU і налагоджувача GDB.

## Варіант

Варіант лабораторної роботи визначається за номером залікової книжки:

```text
3104 % 5 = 4

Отже, виконується варіант №4.

Функція за варіантом:

якщо a*b >= 10:
    result = (a | b) * c

якщо a*b < 10:
    result = (a*b) * c

Для демонстрації використано такі значення:

a = 4
b = 3
c = 5

Обчислення:

a*b = 4*3 = 12
12 >= 10

a | b = 4 | 3 = 7
result = 7*5 = 35

Очікуваний результат:

r0 = 35

У шістнадцятковому вигляді:

r0 = 0x23
Використані інструменти
Ubuntu / WSL
arm-none-eabi-gcc
binutils-arm-none-eabi
gdb-multiarch
make
xPack QEMU ARM
Опис файлів проєкту
start.S - асемблерний файл, який містить таблицю векторів виключень, обробник скидання __hard_reset__ та виклик функції lab1.
lab1.S - основний файл лабораторної роботи, у якому реалізовано обчислення за варіантом 4.
lscript.ld - скрипт лінкера, у якому визначено області пам’яті FLASH та RAM.
Makefile - файл для автоматизації збірки проєкту та запуску емулятора QEMU.
firmware.elf - виконуваний ELF-файл прошивки, який використовується для налагодження в GDB.
firmware.bin - бінарний файл прошивки для запуску в QEMU.
Основні використані інструкції

У програмі використано такі інструкції ARM Cortex-M4:

MOV - завантаження значення в регістр.
MUL - множення значень.
CMP - порівняння значень.
BGE - умовний перехід, якщо значення більше або дорівнює.
B - безумовний перехід.
ORR - побітова операція АБО.
PUSH - збереження значень у стек.
POP - відновлення значень зі стеку.
Збірка проєкту

Для очищення попередніх результатів збірки:

make clean

Для збірки проєкту:

make

Після виконання команди make створюються файли:

start.o
lab1.o
firmware.elf
firmware.bin
Запуск QEMU

Для запуску емулятора QEMU використовується команда:

make qemu

QEMU запускається для плати STM32F4-Discovery з мікроконтролером STM32F407VG та відкриває GDB-сервер на порту 1234.

Підключення GDB

В іншому терміналі потрібно виконати:

gdb-multiarch firmware.elf

Після запуску GDB потрібно підключитися до QEMU:

target extended-remote localhost:1234

Далі встановлюється breakpoint на функцію lab1:

break lab1

Продовження виконання до breakpoint:

continue

Покрокове виконання програми:

step

Перегляд значень регістрів:

info registers
Результат роботи

Після покрокового виконання програми у GDB було перевірено значення регістрів. У регістрі r0 отримано результат обчислення:

r0 = 35

або у шістнадцятковому вигляді:

r0 = 0x23

Це підтверджує правильність реалізації програми за варіантом 4.

Висновок

У результаті виконання лабораторної роботи було створено програму мовою асемблера GAS для мікроконтролера STM32 на базі ядра ARM Cortex-M4. Було реалізовано обчислення за індивідуальним варіантом, використано основні арифметичні, логічні та керуючі інструкції ARM, а також перевірено правильність виконання програми за допомогою QEMU та GDB.
