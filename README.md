## Опис роботи

У межах лабораторної роботи було створено тестовий проєкт у STM32CubeIDE для мікроконтролера STM32F407VG. Оскільки у використаній версії STM32CubeIDE було доступне створення проєкту через `STM32CubeIDE Empty Project`, налаштування GPIO було виконано вручну через регістри мікроконтролера.

У програмі реалізовано налаштування піна PD15 як виходу. На платі STM32F4-Discovery до піна PD15 підключений синій світлодіод. У головному циклі програми стан цього піна періодично перемикається, завдяки чому реалізовано блимання світлодіодом.

## Опис файлів проєкту

- `Src/main.c` - основний файл програми, у якому реалізовано налаштування GPIOD та блимання світлодіодом PD15.
- `Inc/` - директорія з заголовочними файлами проєкту.
- `Startup/` - директорія зі стартовим файлом для мікроконтролера STM32F407VG.
- `STM32F407VGTX_FLASH.ld` - скрипт лінкера для розміщення програми у FLASH-пам’яті.
- `STM32F407VGTX_RAM.ld` - скрипт лінкера для розміщення програми в RAM.
- `gl_starterkit_project.elf` - виконуваний ELF-файл, який використовується для запуску проєкту в QEMU.
