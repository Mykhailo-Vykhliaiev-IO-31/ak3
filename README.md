# Лабораторна робота №1

## Дисципліна

Архітектура комп’ютерів

## Тема

Створення програмного проєкту мовою асемблера

## Виконав

Вихляєв Михайло, група ІО-31

## Мета роботи

Розгорнути програмне забезпечення для роботи з ARM-архітектурою, створити мінімальний програмний проєкт мовою асемблера для STM32, зібрати прошивку та перевірити її працездатність в емуляторі QEMU за допомогою налагоджувача GDB.

## Використані інструменти

- Ubuntu / WSL
- arm-none-eabi-gcc
- binutils-arm-none-eabi
- gdb-multiarch
- make
- xPack QEMU ARM

## Опис файлів проєкту

- `start.S` - асемблерний файл, який містить таблицю векторів виключень та обробник скидання `__hard_reset__`.
- `lscript.ld` - скрипт лінкера, у якому визначено області пам’яті `FLASH` та `RAM`.
- `Makefile` - файл для автоматизації збірки проєкту та запуску емулятора QEMU.
- `firmware.elf` - виконуваний файл прошивки, який використовується для налагодження.
- `firmware.bin` - бінарний файл прошивки.
